# QRForge

A modern QR code generator that lets you create and download QR codes in seconds.

## 🚀 Live Demo

https://tudostrigame-lab.github.io/QRForge/

## ✨ Features

- Generate QR codes from text or URLs
- Download QR codes as PNG
- Clear generated QR codes
- Generate QR codes by pressing Enter
- Responsive design for mobile and desktop
- No registration required
- Simple and fast interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- QRCode.js
- GitHub Pages

## 📱 Usage

1. Enter text or a URL.
2. Click **Create QR Code**.
3. Download your QR code as a PNG image.
